# Changelog

Tất cả những thay đổi nổi bật đối với dự án **Intern Management App (IMA)** sẽ được ghi lại trong file này.

## [1.0.0] - Khởi tạo dự án
### Thêm mới
- Tính năng Quản lý công việc (Task Management) với việc phân chia người giao việc (Assigner) và người thực hiện (Participants).
- Hỗ trợ Import và Export công việc bằng file Excel (tích hợp ExcelJS).
- Giao diện Dashboard quản lý tổng quan.
- Chức năng Báo cáo hằng ngày (Daily Reports).
- Xin nghỉ phép và đề xuất thiết bị (Requests).
- Lịch làm việc (Schedule) hiển thị tổng quan bằng FullCalendar.
- Hệ thống gửi email tự động (Nodemailer) khi có thao tác quan trọng.
- Phân quyền theo vai trò.
